# לומדים לקרוא! 📖

A Hebrew reading app for 1st and 2nd graders (ages 6-7).

## Features

- **Hebrew Letters (אותיות)** - Learn all 22 Hebrew letters with sounds and examples
- **Vowels (ניקוד)** - Learn Hebrew vowel marks (kamatz, patach, tsere, etc.)
- **Syllables (הברות)** - Practice combining consonants with vowels
- **Words (מילים)** - Read simple words with picture hints
- **Sentences (משפטים)** - Read short sentences
- **Audio** - Text-to-speech for every letter, syllable, and word
- **Practice mode** - Interactive quizzes with star rewards
- **Progress tracking** - Stars and level completion saved locally
- **Mobile friendly** - Works on phones, tablets, and desktop

## How to Use

1. Open `index.html` in any modern browser
2. Or visit the GitHub Pages site (enable in repo settings)

## Tech

Pure HTML/CSS/JavaScript - no build tools or dependencies required.

Uses the Web Speech API for Hebrew text-to-speech (works best in Chrome/Safari).
